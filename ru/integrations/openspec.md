# Интеграция с OpenSpec

Используй этот файл, если в проекте есть `openspec/config.yaml`.

Цель: OpenSpec создает каждое изменение с задачами на обновление и проверку гайдов.
Правила не копируй. Давай только ссылку на `docs/DOCS-RULES.md`.

## Шаг 1. Добавь текст в `context`

1. Открой `openspec/config.yaml`.
2. Найди ключ `context`.
3. Добавь этот текст в конец значения. Не удаляй существующий текст.

```yaml
  Документация: правила в docs/DOCS-RULES.md, словарь в docs/glossary.md.
  Используй только термины из словаря.
```

Если ключа `context` нет, создай его как `context: |`. Затем добавь текст под ним.

## Шаг 2. Добавь текст в `rules`

1. Найди ключ `rules`.
2. Добавь эти пункты. Не удаляй существующие пункты.

```yaml
  proposal:
    - Перечисли области, гайды которых изменятся (docs/guide/<область>/).
  specs:
    - Используй термины из docs/glossary.md в значении из словаря.
  tasks:
    - Предпоследняя задача - обновить гайды по docs/DOCS-RULES.md, раздел 6 "Как обновлять".
    - Последняя задача - проверить гайды по docs/DOCS-RULES.md, раздел 7 "Проверка".
```

Если ключа `rules` нет, создай его. Затем добавь текст под ним.

## Как объединить с существующим текстом

1. Если в `rules` уже есть `proposal`, `specs` или `tasks`, не создавай второй такой ключ. Добавь пункты в конец существующего списка.
2. Если новый пункт противоречит существующему, не меняй существующий пункт. Спроси пользователя.
3. Сохрани отступы файла. YAML не работает с неверными отступами.
4. Не меняй другие ключи файла.

Пример для сервиса библиотеки.

До:

```yaml
context: |
  Сервис библиотеки: книги, читатели, выдачи.

rules:
  tasks:
    - Каждая задача меняет одну область.
```

После:

```yaml
context: |
  Сервис библиотеки: книги, читатели, выдачи.
  Документация: правила в docs/DOCS-RULES.md, словарь в docs/glossary.md.
  Используй только термины из словаря.

rules:
  proposal:
    - Перечисли области, гайды которых изменятся (docs/guide/<область>/).
  specs:
    - Используй термины из docs/glossary.md в значении из словаря.
  tasks:
    - Каждая задача меняет одну область.
    - Предпоследняя задача - обновить гайды по docs/DOCS-RULES.md, раздел 6 "Как обновлять".
    - Последняя задача - проверить гайды по docs/DOCS-RULES.md, раздел 7 "Проверка".
```
