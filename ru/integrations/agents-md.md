# Интеграция с файлами инструкций для агентов

Используй этот файл, если в проекте есть файл инструкций для ИИ-агента.

Цель: агент знает о правилах документации в каждой сессии.
Правила не копируй. Давай только ссылку на `docs/DOCS-RULES.md`.

## Шаг 1. Найди файлы инструкций

Проверь корень проекта. Для каждого файла запиши: есть или нет.

| Инструмент | Файл |
|---|---|
| Разные агенты | `AGENTS.md` |
| Claude Code | `CLAUDE.md` |
| GigaCode | `GIGACODE.md` |

Если файла нет ни одного, спроси пользователя, какой инструмент использует команда. Не создавай файл сам.

## Шаг 2. Добавь раздел

Добавь этот текст в конец каждого найденного файла. Не меняй остальной текст файла.

```markdown
## Документация
- Правила: `docs/DOCS-RULES.md`. Словарь: `docs/glossary.md`.
- После изменения спецификации или поведения кода обнови гайды по `docs/DOCS-RULES.md`, раздел 6 "Как обновлять".
- Для доменных понятий используй только термины из словаря.
```

## Как объединить с существующим текстом

1. Если в файле уже есть раздел "Документация", не создавай второй. Добавь строки в конец этого раздела.
2. Если строка противоречит существующему тексту, не меняй существующий текст. Спроси пользователя.
3. Если один файл только ссылается на другой, добавь раздел в тот файл, на который он ссылается.
