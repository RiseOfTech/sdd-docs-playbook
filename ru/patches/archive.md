# Патч для навыка архива

Тип навыка: архив или завершение. Как определить тип и как применить патч, смотри в `ru/patches/README.md`.

## Куда вставить

Вставь текст первым шагом навыка. Этот шаг должен стоять перед архивом.

## Текст патча

```markdown
- Перед архивом выполни навык `docs-review`. Если в отчете стоит "Итог: есть ошибки", не архивируй. Покажи ошибки пользователю.
- Если этого навыка нет в проекте, проверь гайды по `docs/DOCS-RULES.md`, раздел 7 "Проверка". Если есть пункты "нет", не архивируй. Покажи их пользователю.
```
