# Патч для навыка создания спецификации

Тип навыка: создание спецификации. Как определить тип и как применить патч, смотри в `ru/patches/README.md`.

## Куда вставить

Вставь текст в шаг, на котором навык пишет спецификацию или описание изменения.
Если такого шага нет, вставь текст последним шагом перед выводом результата.

## Текст патча

```markdown
- Для доменных понятий используй только термины из `docs/glossary.md`. Правила: `docs/DOCS-RULES.md`, раздел 4 "Словарь".
- Перечисли в описании изменения области, гайды которых изменятся (`docs/guide/<область>/`). Имена областей копируй из `docs/MAP.md`.
```
