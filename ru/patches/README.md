# Патчи для существующих навыков

Патч — короткая вставка в навык проекта. Патч связывает навык с `docs/DOCS-RULES.md`.
**НЕ ЗАМЕНЯЙ НАВЫКИ ПРОЕКТА.** Добавляй в них только патч.

## Как применить

1. Открой папку навыков проекта. Она лежит в корне проекта. Имя папки зависит от инструмента:
   - Claude Code: `.claude/skills/`;
   - GigaCode: `.gigacode/skills/`;
   - OpenCode: `.opencode/skills/`;
   - общая папка для разных агентов: `.agents/skills/`.

   Имена этих папок начинаются с точки. Файловый менеджер может их скрывать. Открой проект в редакторе кода: там эти папки видны.
   Если ни одной папки нет, спроси ответственного за разработку проекта, где лежат навыки.
2. Прочитай навык. Определи его тип по таблице.
3. Открой файл из колонки "Патч".
4. Вставь текст патча в шаги навыка.
5. Не меняй остальной текст навыка.

Если навык подходит под два типа, спроси пользователя.
Если навык не подходит ни под один тип, оставь его без изменений.

## Таблица типов

| Тип навыка | Признак | Патч | Что делает патч |
|---|---|---|---|
| Ревью кода или задач | "review", "проверь", чек-лист | `review.md` | Добавляет проверку гайдов в чек-лист ревью. |
| Реализация | "implement", "apply", выполняет задачи | `implement.md` | Добавляет вызов `docs-sync` перед завершением. |
| Создание спецификации | "propose", "spec", "new change" | `propose.md` | Требует термины из словаря и список областей, гайды которых изменятся. |
| Архив или завершение | "archive", "done", "release" | `archive.md` | Запрещает архив, если `docs-review` нашел ошибки. |
| Нужного навыка нет | — | — | Патч не нужен. Возьми новый навык из `ru/skills/`. |

## Правила патча

1. Патч — это 1–3 строки и ссылка на `docs/DOCS-RULES.md`.
2. Не копируй правила в патч.
3. Один навык = одна задача. Не объединяй ревью кода и написание гайдов в один навык.
4. Если два навыка противоречат друг другу, сообщи пользователю. Не исправляй сам.
