# Патч для навыка реализации

Тип навыка: реализация. Как определить тип и как применить патч, смотри в `ru/patches/README.md`.

## Куда вставить

Вставь текст последним шагом перед завершением навыка.
Если навык выводит итоговый отчет, вставь текст перед этим шагом.

## Текст патча

```markdown
- Перед завершением выполни навык `docs-sync`. Если этого навыка нет в проекте, обнови гайды по `docs/DOCS-RULES.md`, раздел 6 "Как обновлять".
```
