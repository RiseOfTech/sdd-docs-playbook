# sdd-docs-playbook

Библиотека рецептов для понятной и актуальной документации в проектах со SDD (spec-driven development).

Библиотеку не устанавливают. Из нее копируют шаблоны, промпты и навыки в свой проект.

> Статус: черновик. Готовы правила, шаблоны, промпты, патчи, навыки обновления и проверки. Смотри таблицу "Что есть в репозитории".

## Для кого

Для аналитиков, разработчиков и тимлидов. Подходит для проектов с OpenSpec, Spec Kit или без SDD.

## Какую проблему решает

Новый человек открывает карту проекта. Карта показывает, какие гайды читать.
Правила записаны в одном файле. Навыки и инструкции агентов только ссылаются на него.

## Что получит проект

```
docs/
├── MAP.md            карта проекта: точка входа для нового человека
├── ONBOARDING.md     маршрут чтения по ролям
├── DOCS-RULES.md     единые правила
├── glossary.md       словарь: один термин = одно значение
└── guide/
    ├── _template/    шаблоны гайдов
    └── <область>/
        ├── analyst.md   что и зачем
        └── dev.md       как и где
```

## Как это работает

1. Один раз создай документацию: карту, словарь, правила, первые гайды.
2. Один раз подключи навыки: скопируй `docs-sync` и `docs-review`, вставь патчи в навыки проекта.
3. Затем работай как обычно.
4. После реализации изменения `docs-sync` обновляет гайды, словарь и карту.
5. Перед ревью и архивом `docs-review` проверяет документацию.
6. Если `docs-review` нашел ошибки, патч `archive.md` запрещает архив.

## Быстрый старт

1. Создай папку `docs/` в своем проекте.
2. Скопируй `ru/templates/docs/DOCS-RULES.md` в `docs/DOCS-RULES.md`.
3. Скопируй `ru/templates/docs/MAP.md` в `docs/MAP.md`.
4. Скопируй `ru/templates/docs/glossary.md` в `docs/glossary.md`.
5. Заполни карту. Инструкция стоит в начале файла.
6. Добавь в `AGENTS.md`, `CLAUDE.md` или `GIGACODE.md` этот раздел:

   ```markdown
   ## Документация
   - Правила: `docs/DOCS-RULES.md`. Словарь: `docs/glossary.md`.
   - После изменения спецификации или поведения кода обнови гайды по `docs/DOCS-RULES.md`, раздел 6 "Как обновлять".
   - Для доменных понятий используй только термины из словаря.
   ```
7. Если в проекте есть навыки, подключи их по `ru/patches/README.md`.

Чтобы эту работу выполнил ИИ-агент, запускай промпты из `ru/prompts/` по порядку: от `00-explore.md` до `04-integrate.md`.
Для небольшого проекта используй один промпт: `ru/prompts/full-setup.md`.

## Что есть в репозитории

| Путь | Что это | Статус |
|---|---|---|
| `ru/templates/docs/` | Шаблоны: правила, карта, маршрут, словарь, гайды | Готово |
| `ru/prompts/` | Одноразовые задания агенту | Готово |
| `ru/patches/` | Вставки в навыки проекта. Начни с `ru/patches/README.md` | Готово |
| `ru/skills/docs-sync/`, `ru/skills/docs-review/` | Навыки обновления и проверки | Готово |
| `ru/integrations/openspec.md`, `ru/integrations/agents-md.md` | Настройка под OpenSpec и файлы инструкций агентов | Готово |
| Другие файлы в `ru/skills/` и `ru/integrations/` | Остальные навыки и интеграции | В работе |
| `ru/concepts/` | Объяснение идеи для людей | В работе |
| `ru/notes/` | Большие проекты, слабые модели | В работе |
