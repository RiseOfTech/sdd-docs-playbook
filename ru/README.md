# sdd-docs-playbook

Библиотека рецептов для понятной и актуальной документации в проектах со SDD (spec-driven development).

Библиотеку не устанавливают. Из нее копируют шаблоны, промпты и навыки в свой проект.

> Статус: черновик. Сейчас готово только ядро. Смотри таблицу "Что есть в репозитории".

## Для кого

Для аналитиков, разработчиков и тимлидов. Подходит для проектов с OpenSpec, Spec Kit или без SDD.

## Какую проблему решает

Новый человек открывает карту проекта. Карта показывает, какие гайды читать.
Правила записаны в одном файле. Навыки и инструкции агентов только ссылаются на него.

## Что получит проект

```
docs/
├── MAP.md            карта проекта: точка входа для нового человека
├── ONBOARDING.md     маршрут чтения по ролям
├── DOCS-RULES.md     единые правила
├── glossary.md       словарь: один термин = одно значение
└── guide/
    ├── _template/    шаблоны гайдов
    └── <область>/
        ├── analyst.md   что и зачем
        └── dev.md       как и где
```

## Быстрый старт

1. Создай папку `docs/` в своем проекте.
2. Скопируй `ru/templates/docs/DOCS-RULES.md` в `docs/DOCS-RULES.md`.
3. Скопируй `ru/templates/docs/MAP.md` в `docs/MAP.md`.
4. Заполни карту. Инструкция стоит в начале файла.
5. Добавь в `AGENTS.md` или `CLAUDE.md` этот раздел:

   ```markdown
   ## Документация
   - Правила: `docs/DOCS-RULES.md`. Словарь: `docs/glossary.md`.
   - После изменения спецификации или поведения кода обнови гайды по `docs/DOCS-RULES.md`, раздел 6 "Как обновлять".
   - Для доменных понятий используй только термины из словаря.
   ```
6. Если в проекте есть навыки, подключи их по `ru/patches/README.md`.

## Что есть в репозитории

| Путь | Что это | Статус |
|---|---|---|
| `ru/templates/docs/DOCS-RULES.md` | Единые правила: письмо, словарь, обновление, проверка, отчет | Готово |
| `ru/templates/docs/MAP.md` | Шаблон карты проекта | Готово |
| `ru/patches/README.md` | Как определить тип навыка и что в него вставить | Готово |
| `ru/patches/` | Файлы патчей | В работе |
| `ru/templates/docs/` | Остальные шаблоны: маршрут, словарь, гайды | В работе |
| `ru/prompts/` | Одноразовые задания агенту | В работе |
| `ru/skills/` | Новые навыки для копирования | В работе |
| `ru/integrations/` | Настройка под конкретный инструмент | В работе |
| `ru/concepts/` | Объяснение идеи для людей | В работе |
| `ru/notes/` | Большие проекты, слабые модели | В работе |
