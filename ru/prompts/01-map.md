# Задача: создать карту проекта

Ты — ИИ-агент. Ты работаешь в репозитории проекта.
Прочитай эту инструкцию полностью. Затем выполняй шаги по порядку.

Цель: показать области проекта и документы по каждой области.
Результат: файлы `docs/DOCS-RULES.md` и `docs/MAP.md`. Гайды на этом этапе не пиши.

## Главные правила

1. Выполняй шаги строго по порядку. Не пропускай шаги.
2. На шаге с пометкой **СТОП** покажи результат пользователю. Жди ответа. Не продолжай без ответа.
3. Изменяй только файлы `docs/DOCS-RULES.md`, `docs/MAP.md` и `docs/_setup/progress.md`.
4. Не изменяй код программы и спецификации.
5. Не придумывай имена областей, файлов и папок.
   Каждое имя копируй из `docs/_setup/inventory.md` или из папки, которую ты открыл в этой сессии.
6. Если ты не уверен в факте, напиши в тексте `[ПРОВЕРИТЬ: <что именно>]`. Не угадывай.
7. Не делай коммиты и не создавай ветки, если пользователь не попросил.
8. Если инструкция противоречит правилам проекта (`AGENTS.md`, `CLAUDE.md`, `GIGACODE.md` и т. п.), остановись и спроси пользователя.

**Если работа прервалась:** открой `docs/MAP.md`. Продолжи с первого незаполненного блока.

## Шаг 1. Прочитай результат предыдущего этапа

1. Открой `docs/_setup/inventory.md`.
2. Открой `docs/_setup/progress.md`.

Если одного из файлов нет, остановись. Скажи пользователю: "Сначала выполни промпт `00-explore.md`."

## Шаг 2. Скопируй шаблоны

Скопируй файлы из библиотеки `sdd-docs-playbook`:

| Откуда | Куда |
|---|---|
| `ru/templates/docs/DOCS-RULES.md` | `docs/DOCS-RULES.md` |
| `ru/templates/docs/MAP.md` | `docs/MAP.md` |

Пути `ru/...` начинаются от папки библиотеки. Обычно она лежит рядом с проектом: `../sdd-docs-playbook/`.
Если у тебя нет доступа к файлам библиотеки, остановись. Попроси пользователя дать доступ по файлу библиотеки `ru/README.md`, раздел "Подготовка". Не пиши текст файлов библиотеки по памяти.
Если файл уже есть в `docs/`, остановись и спроси пользователя.

## Шаг 3. Заполни карту

Выполни инструкцию в начале `docs/MAP.md`. Учитывай эти условия:

- Оставь строку `docs/ONBOARDING.md` в таблице "Где найти ответ". Файл появится на этапе 03.
- В колонке "Гайды" напиши "нет". Гайды появятся на этапе 03.
- Если владелец области неизвестен, напиши `[ПРОВЕРИТЬ: владелец области]`.
- Если служебных областей нет, удали раздел "Служебные области".
- Раздел "Другие документы" заполни из раздела "Существующая документация" файла `inventory.md`. Если документов нет, удали раздел.

## Шаг 4. Проверь карту

Выполни `docs/DOCS-RULES.md`, раздел 7 "Проверка". Используй только блок "Карта (`docs/MAP.md`)". Исправь все пункты "нет".

## Шаг 5. Обнови прогресс

1. Отметь этап 01 в `docs/_setup/progress.md`.
2. Добавь каждую область в таблицу "Области".

**СТОП.** Покажи пользователю `docs/MAP.md`. Отдельным списком покажи все пометки `[ПРОВЕРИТЬ]`. Спроси:
1. Понятны ли названия блоков?
2. Верен ли порядок чтения?
3. Кто владелец областей без владельца?

Жди ответа. После ответа исправь карту.
